# HyperFrames Skill Suite for Claude Code

7 battle-tested Claude Code skills that teach your AI agent how to properly use the open-source [HyperFrames CLI](https://github.com/heygen-com/hyperframes) (by HeyGen) for subtitle rendering, motion graphics, and keyframe animation on video — not just a list of prompts, but a working pipeline covering architecture, CLI wrapping, animation, creative presets, keyframe logic, and a preset registry.

**Dependency disclosure:** this suite requires a separate install of the open-source [HyperFrames CLI](https://github.com/heygen-com/hyperframes) by HeyGen. These skills are instructions for Claude Code, not a reimplementation of the CLI itself.

## What's included

- `hyperframes` — core overview skill and lifecycle
- `hyperframes-core` — architecture and render review loop
- `hyperframes-cli` — CLI wrapper, cloud rendering, installation
- `hyperframes-animation` — animation primitives and transitions
- `hyperframes-creative` — creative styling presets, fonts (Inter, EB Garamond, JetBrains Mono, OFL-licensed)
- `hyperframes-keyframes` — keyframe animation logic
- `hyperframes-registry` — preset registry and discovery
